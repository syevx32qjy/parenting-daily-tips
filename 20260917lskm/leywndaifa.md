# 【吐露“新”生系列120】我的小龙宝出生啦！感谢管一春院长！

> 更新时间：2026-09-17 (UTC+8)

与其说这是一封感谢信，倒不如说是我的求子历程，希望我的故事，给正在求子路上的姐妹们一些鼓励和启发。

2020年，我32岁，结婚3年，备孕2年，然而宝宝并没有来。于是第一次疫情开放后的5月份我第一次踏入了郑州大学第三附院生殖医学科（现在已经是生殖健康医院了）。

由于我老公是畸形精子症，且已经在外院做过一次人工授精未孕，所以这次我毅然决然选择试管婴儿助孕。就这样在医生的指导下，我开始检查、促排、取卵、移植，然而我经历了一次宫外孕、一次未孕、一次胚胎停育后，万分沮丧，不知何去何从，不知道助孕之路该如何坚持下去。

但是，我并不是一个轻言放弃的人，当时因为疫情不方便出门，我也趁机休整了一段时间，最后决定找管一春院长。

2022年7月，我第一次见到了和蔼可亲又温柔可敬的管院长，也第一次见到了干净利索又热情漂亮的缑洋护士。管院长详细看了我的病历，认真仔细分析失败原因，最后根据我们夫妻的具体情况，给我定制个性化诊疗方案，这次我获得了两枚鲜胚，一枚冻胚，三枚囊胚。

可是我满怀信心的鲜胚移植却依然以失败告终，管院长察觉到我的情绪已经到了崩溃的边缘了，开始耐心的开导我、安慰我，我能感受到管院长是理解我的，是能与我共情的，这让我很感动。

2022年12月左右，本来准备再次开启试管移植之路，因为疫情，我拖到了2023年4月份，移植了两枚囊胚，14天后，第一次见到了尿HCG试纸条显示双红杠，我激动不已，然而血HCG数值并不高，我又很担心，缑洋护士亲切的告诉我说：“先别气馁，可能着床晚呢，咱们先看看复查情况吧。”没想到最后还是生化妊娠了，我彻底崩溃了，在楼梯口嚎啕大哭！为什么天使没有降临我家，试管这条路太难了！

最后一次移植机会了，我决定让自己静下心来，好好复盘在助孕过程中自己有哪些做的不够好，我要做好充分的准备再去移植，让自己不留遗憾。

我听管院长的话，先去做了心理疏导，按照心理咨询师的建议，每日进行正念减压，做自己喜欢的事，分散自己的注意力，让自己保持一个轻松的心理状态。我有胰岛素抵抗，体重也重，这次我决心听管院长的话好好运动，控制饮食，努力减重，调整作息，规律生活。

调整了两个月后，我身体的各项指标也越来越好，我感觉自己也做好了充分的准备，这次管院长制定了适合我的序贯移植方案，并建议我放松心情、住院留观，我都照做了，2023.8.8，我看到了一个很大很美的数字——血HCG1986IU/L，我欣喜若狂，我成功了！看到这个数字时，管院长一把把我拥入怀中，她比我还要激动。毫不夸张的说，当时我看到管院长的每一根头发都在发光。

2024年3月底，我的小龙宝出生了，他的第一声啼哭是生命的宣言，我也情不自禁的流泪了。我终于做妈妈了！再次感谢管一春院长和缑洋护士给了我做妈妈的机会，送给我一个天使宝贝！

患者：星星（化名）

2024年4月2日
